# サポート

Red Panda は iPhone・iPad 用の ToDo とメモのアプリです。メモを入力または音声で入れ、終わったらスワイプして、
パンダを喜ばせましょう。

## ご質問・不具合

[github.com/goosalex/red_panda/issues](https://github.com/goosalex/red_panda/issues) で issue を作成してください。
お使いの iPhone または iPad、iOS のバージョン、Red Panda のバージョン（設定 > 新機能）を書いてください。
issue は公開されるため、個人情報は書かないでください。

## よくある質問

**出かけてもお出かけかごが知らせてくれません。**
Red Panda で 設定 > お出かけかご を開き、位置情報の許可を確認してください。「使用中のみ」では、アプリを
開いている間しか iOS は離れたことを知らせません。「常に」なら iOS がアプリを起こせます。Wi-Fi については、
設定 > お出かけかご >「Wi-Fiから離れたとき」に表示されるショートカットのオートメーションを追加してください。

**音声メモが録音されません。**
Red Panda にはマイクと音声認識の許可が必要です。アプリ内の青いリンクから iOS の設定の該当箇所に移動できます。

**メモがほかのデバイスに表示されません。**
各デバイスの Red Panda で 設定 > iCloud同期 をオンにし、iOS の設定で iCloud Drive がオンになっているか確認してください。

**Red Panda をロック画面、ホーム画面、コントロールセンター、アクションボタンに追加するには？**
設定 > クイックキャプチャ で、それぞれの場所を手順の動画つきで確認できます。

## プライバシー

Red Panda はデータを一切収集しません。[プライバシーポリシー](../privacy/)をご覧ください。
